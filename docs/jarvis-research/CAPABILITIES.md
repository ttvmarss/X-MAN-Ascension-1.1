# Capabilities & Kit Tiers

## Ten capabilities marketed on the landing page

1. Voice Interaction — wake word + real-time conversation  
2. Long-Term Memory — people, preferences, projects, past chats  
3. File Management — find / organize / rename / reason over docs  
4. Browser Automation — navigate, forms, research  
5. Application Control — open/drive apps from speech  
6. AI Agents — multi-agent planning / delegation  
7. Workflow Automation — schedule or voice-triggered flows  
8. Personal Knowledge Base — searchable second brain  
9. Real-Time Diagnostics — live system health HUD  
10. Neural Interface — holographic reactive UI

Own **Claude Pro ($20/mo)** + **Anthropic API tokens** (billed separately).

## Philosophy differences (landing “Why different”)

Persistent memory · always-listening voice · personalization · action across tools · living HUD · modular · local control · multi-agent · you own the system (vs renting a chatbot).
